# Mon Programme Sport 🏋️‍♀️

PWA mono-usage pour planifier son programme d'entraînement (corde à sauter, pilates, running, muscu...) et noter ce qu'on a réellement fait, avec un dashboard "cette semaine" (séances, minutes, streak).

- **Semaine** : dashboard croisé planifié / réalisé, jour par jour.
- **Programme** : les séances types par jour (ou "jour libre"), avec objectif.
- **Journal** : le log réel de chaque séance (valeur, ressenti, note), lié ou non à une séance planifiée.

Aucun backend : les données restent en `localStorage` sur l'appareil. Export/import JSON dans les réglages (⚙️) pour sauvegarder ou changer d'appareil.

Vanilla JS, pas de build. Ouvrir `index.html` ou servir le dossier statiquement.
